# Structural Analyzer

A browser-based 2D structural analysis application built using:

- Python
- Flask
- NumPy
- HTML/CSS/JavaScript

---

## Features

### Modeling
- Node creation
- Member creation
- Support assignment
- Nodal loads
- Member loads

### Load Types
- Point Load
- UDL
- Partial UDL
- Trapezoidal Load
- Member Moment

### Analysis
- Global stiffness method
- Member end forces
- Reactions
- Nodal displacements

### Post Processing
- Shear Force Diagram (SFD)
- Bending Moment Diagram (BMD)
- Deflection diagrams
- Structure visualization
- Zoom and pan
- Diagram scaling controls
